Keybinds

Click a keybind, then press the key you want. Keybinds work only while the game is in front. The game itself uses F1 to F6.

A character's row is drawn in the colour of its element. The meter on this page shows a colour while you pick it.

When and how it shows

Switch on the figures a row shows. The arrows change their order: the top one is the leftmost. With four or five, the bar beside the name gives way to them.

Boss HP tables

What the meter knows each boss's HP and name from. After a game patch, update them: about 260 MB is downloaded, and deleted again once the tables are built.

Waveband updates

Waveband asks GitHub for a newer version when it starts and once a day. An installed copy updates itself; the zip copy says where to download the new one.
